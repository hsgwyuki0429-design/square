# SIKAKU — 四角のアトリエ

依存パッケージなしの静的Webアプリ。`npm start` で http://localhost:5173 を起動、`npm test` で検証します。`dist/` をそのまま静的ホスティングに配置できます。

## 機能

短辺・長辺（0.01〜1000、小数2桁）、自動入れ替え、横/縦、基本・モザイク・集中、タップで集中位置変更、分割予算、密集強度、3配色、輪郭線、シード、正方形の情報、ピンチ/ホイール拡大、ドラッグ、全体表示、再生/停止/再開/最初から再生。

## 正確さ

`geometry.mjs` がCanvasと独立した幾何データを生成します。入力を文字列から1/100単位の整数に変換。ユークリッド式の最大正方形配置後、座標を `6^8` 倍し、2×2または3×3へ8階層まで再分割します。すべての座標・一辺は安全な整数の範囲にあり、面積比較にはBigIntを使います。生成時には境界、正の一辺、ペアの重なり、面積を独立に検証します。有限の境界内正方形集合が重ならず面積が一致するため、内部に未充填領域はありません。輪郭線は描画装飾です。

アニメーションは基本分割から開始し、保存された親→子イベントを順に適用します。再生成はrequestAnimationFrameを取り消し、表示データを完成状態へ置き換えます。画面外パーツを描画せず、1画素以下では輪郭線を省略。アニメーションの自動再生は行わず、動きを減らす設定への変更時には停止します。

## 検証

幾何学テスト：60×100→60,40,20,20、100×100、7×13、2.5×4、入れ替え、最小値、997.5×1000、3モード×2向き。アニメーション途中の充填、再現性、意図的な重複・欠落の検出、4000個の負荷を検証。

イベントテスト：2ポインターのピンチ、ホイール、ドラッグ、全体表示、再生成による古いフレームの中止、一時停止/再開、無効入力で直前の結果を維持。

ブラウザー：デスクトップおよび390×844表示で入力、生成、入れ替え、正方形、拡大、向き、選択情報、集中位置、配色、輪郭線、再生、再生成、エラーを確認。WebMCP生成ツールも有効入力・無効入力を確認。

## 制限

- 基本分割は6000個まで。極端な縦横比だけでなく、999.99×1000のような細い余りを生む入力も上限で拒否します。寸法を黙って変更しません。
- 再分割予算は最大4000（基本分割がこれを超える場合は基本個数を保持）、深さ8、表示拡大率25〜10000%。
- 選択情報の長さ・面積は9桁の概数表示。内部の幾何データ・面積比較は整数のままです。
- 実機iOS/Androidでのマルチタッチは未確認。ブラウザーのスマートフォン幅と同じイベントハンドラーの2ポインター試験で検証しました。
- Google Fonts未接続時はシステムフォントで動作。ログイン・保存機能はアプリ自体にはありません。Sites配信のアクセス制限は別です。
